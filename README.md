# 🚴 MyBike — Modern Bicycle Landing Page

**MyBike** is a stylish and responsive landing page dedicated to modern bicycles. The project features a clean design, intuitive navigation, and a user-friendly interface, providing an engaging experience across different devices.

Built with HTML, SCSS, and JavaScript, the website focuses on responsive layouts, reusable components, and modern front-end development practices.

## 🌐 Live Preview

**[View Live Demo →](https://ggylyon.github.io/MyBike/)**

## 🛠 Technologies Used

- **HTML5** — semantic markup and page structure.
- **SCSS (Sass)** — modular styling, variables, and reusable styles.
- **CSS3** — responsive layouts, transitions, and visual effects.
- **JavaScript** — interactive elements and dynamic functionality.
- **BEM Methodology** — structured and maintainable CSS class naming.
- **Parcel** — bundling and development tooling.
- **Git & GitHub** — version control and project hosting.

- 📱 **Responsive Design** — layouts adapted for desktop, tablet, and mobile devices.
- 🎨 **Modern UI** — clean typography, engaging visuals, and consistent styling.

## ⚙️ Getting Started

Follow these instructions to set up and run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (LTS version recommended)
- npm
- Git

### Installation

**1. Clone the repository:**

```bash
git clone https://github.com/ggylyon/MyBike.git
```

**2. Navigate to the project directory:**

```bash
cd MyBike
```

**3. Install dependencies:**

```bash
npm install
```

**4. Start the development server:**

```bash
npm start
```

**5. Open the local URL displayed in your terminal.**
